# Icons

These icons come from the [AoE4 World data repo](https://github.com/aoe4world/data) by Robert van Hoesel and AoE4 World. Only the icons the library uses are copied here, by `pnpm subjects icons` (see `scripts/subjects.ts`). Any other icon is shown straight from data.aoe4world.com until the script copies it.
